# Nature Social Science — Research Topics and Arguments

<!-- English edition: modified 2026-10-20; see EDITION-NOTICE.md at package root. -->

English adaptation: translated and condensed for this edition; original workflow attribution is retained.

Support quantitative, qualitative, ethnographic, archival, documentary, corpus, and digital research. Judge question clarity, evidence fit, honest claims, and whether this researcher can complete the project. Default to English; respect an explicitly requested output language.

Do not promise a correct topic, novelty, admission, funding, publication, or thesis success. AI confidence is not evidence; a completed worksheet does not automatically pass a gate. Do not prefer any method by default.

All reference names in this table are relative to `references/`.

Choose an entry mode first: **Mode A** for an interest; **Mode B** for a broad topic or relationship; **Mode C** for a tentative research question. Mode C is an **audit route**, not an advanced route or exemption. With only a dataset or method preference, ask what unresolved phenomenon it could illuminate; if unclear, begin in Mode A.

## Four iron rules

1. Record missing information as **unknown**; do not guess it into existence.
2. Actively seek **contradictions, null results, reverse relationships, and alternative explanations**.
3. Preserve source evidence levels, route evidence states, failed searches, and decisive unknowns.
4. Update **Current Research State** after each step; do not pass the whole old conversation to the next step.

**Do not fabricate citations, sources, or results.** Keep this prohibition in every prompt. Before the relevant stage, do not generate titles, hypotheses, or questions; assert a gap or novelty; presume a method; equate no result in this search with no research anywhere; or turn personal interest into demonstrated scholarly importance.

## Twelve distinctions

| Distinction | Check |
|---|---|
| Interest ≠ Topic | Have phenomenon, process, and boundaries been identified? |
| Topic ≠ Research problem | What specifically remains unexplained? |
| Research problem ≠ Research question | Can evidence advance the proposed inquiry? |
| Research gap ≠ few studies | What knowledge consequence follows from the missing work? |
| Novelty ≠ nobody has studied it | Does it resolve contradiction, mechanism, measurement, or a newly answerable problem? |
| Interesting ≠ Important | Whose understanding would change, beyond personal interest? |
| Important ≠ Answerable | Is suitable, lawful, timely evidence available? |
| Available source ≠ Valid evidence | Do observations or materials match the construct? |
| Correlation ≠ Mechanism | Is a process observed, or only co-occurrence? |
| Advanced method ≠ Strong contribution | Does the method solve the original knowledge difficulty? |
| Feasible study ≠ PhD-worthy project | Can one central puzzle support coherent development? |
| AI judgement ≠ Researcher judgement | Which commitments, risks, and choices belong to the researcher? |

## Eight-step workflow

| Step | Main output | Gate question |
|---|---|---|
| 1. Research Search Space | One-page search space | Are concepts and boundaries searchable? |
| 2. Research Landscape | Field map | Are multiple problems, explanations, and counterevidence visible? |
| 3. Unresolved Problems | 3–7 problem cards | Is there consequential knowledge uncertainty? |
| 4. Evidence Map | 1–3 examined evidence routes | Can the core problem be observed within a claim ceiling? |
| 5. Candidate RQs | Usually 6–12 candidate cards | Are questions substantively different and open to criticism? |
| 6. Academic Survival | Novelty Audit and Reviewer 2 Sheets | Do candidates survive serious objections? |
| 7. PhD Feasibility | Feasibility dossiers | Are hard failures addressed and coherent PhD development possible? |
| 8. Final Shortlist | At most three Topic Cards | Are trade-offs and decisive next checks clear? |

Step 5 briefly expands before narrowing. This is not a purely linear pipeline. If design supplies weak proxies, wrong units, or unsuitable timing, return to Question. If the knowledge consequence disappears, return to Problem.

## Keep five status systems separate

| System | Values |
|---|---|
| Workflow Gate | PASS / REVISE / STOP; PARK can suspend a direction from Step 5 onward |
| Evidence State | NAMED / DOCUMENTED / ACCESS-CONFIRMED / TESTED |
| Academic Survival | SURVIVE / REDESIGN / PARK / REJECT |
| PhD Feasibility Dependency | CONFIRMED / RESOLVABLE DEPENDENCY / UNKNOWN / FAIL |
| PhD Feasibility Disposition | PROCEED TO COMPARISON / REDESIGN / PARK / REJECT |

Preserve `UNKNOWN ≠ PASS`, `DOCUMENTED ≠ ACCESS-CONFIRMED`, `SURVIVE ≠ novel`, `PARK ≠ bad idea`, `PASS ≠ permanent approval`, and `REJECT ≠ wasted work`. Never invent a composite status or let a positive result in one system erase failure in another.

## Working rhythm and human handoff

Read the current step's purpose and gate, use its prompt, complete its worksheet, inspect quality checks and Red flags, then update Current Research State. Carry current decisions and evidence; retain detailed logs separately.

Quick Run and Deep Run exist for Steps 2, 4, 6, and 7. Quick Run reduces initial effort, not evidence, ethics, access, or hard-failure standards. It does not replace deeper audit.

Refer unresolved disciplinary significance, inaccessible decisive full texts, sensitive participants, risky materials, uncertain training burden, or dependencies on supervisors and source holders to an appropriate person. AI can prepare the question; it cannot grant permission or make their decision.

`05-prompt-library.md` is the authoritative English prompt version for this edition.
