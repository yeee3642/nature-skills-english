# Optional multilingual-input support

<!-- English edition: modified 2026-10-20; see EDITION-NOTICE.md at package root. -->

Use this reference for non-English availability notes or an explicitly requested translation.

- Draft the Data Availability statement in English by default.
- Preserve intended access conditions and identify unresolved author decisions.
- Informal wording such as "available from the corresponding author" is insufficient without the restriction reason and access process.
- Distinguish raw, processed, and figure source data; Supplementary Information; repositories and accession numbers; restricted and de-identified data; and Code Availability.
- A reasonable-request route needs a justification, eligibility criteria, and a review route.
- Read `references/chinese-author-alignment.md` for precise terminology and intake questions.
- Add bilingual explanations only when explicitly requested; otherwise keep author checks in English.
