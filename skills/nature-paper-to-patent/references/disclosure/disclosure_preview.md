# Disclosure preview (Step 6)

<!-- English edition: modified 2026-10-20; see EDITION-NOTICE.md at package root. -->

Before a long draft, present a compact working title, one to three technical problems linked to the closest prior art, the core modules or steps, and an evidence-grounded account of the distinction. Reuse a direction the user has already approved. If the request authorizes drafting or explicitly skips preview, continue to `disclosure_builder.md` without introducing another approval loop.

Keep repository names, internal scripts, teaching-example labels, and boilerplate tool commentary out of the disclosure body. Explain material uncertainty separately from the technical document.
