# Optional multilingual-input support

<!-- English edition: modified 2026-10-20; see EDITION-NOTICE.md at package root. -->

Load this reference when source text is not English or the user explicitly requests translation support.

- Accept source manuscript text in its original language and preserve exact source segments.
- Convert each source claim into English concept queries unless the topic requires language-specific scholarship.
- Return segment notes and evidence notes in English by default. Use another output language only when explicitly requested.
- Label evidence as `strong support`, `partial support`, `background support`, or `not suitable as support for this claim`.
- A related title alone does not establish support for the manuscript claim.
