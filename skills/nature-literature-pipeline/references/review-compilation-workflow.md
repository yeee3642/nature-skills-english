# Focused Literature Review Compilation

<!-- English edition: modified 2026-10-20; see EDITION-NOTICE.md at package root. -->

Use this workflow after a topic is established to turn an existing collection
into an evidence-led review. It complements daily discovery rather than replacing
the recurring pipeline.

## Inventory the existing collection

Search the supplied vault and configured reference manager using topic keywords,
including appropriate language variants when needed. Broaden one search to catch
missed records. Read core draft pages and extract their cited sources. Deduplicate
across notes and the reference manager, then classify records as directly relevant,
partly relevant, or background. Map coverage to the proposed review questions and
identify thin subtopics. Use tools actually available in the environment rather
than assuming a specific vault integration.

## Fill evidence gaps

Look for missing material systems, mechanisms, timescales, measurement approaches,
and research groups. Search targeted keyword combinations and follow backward and
forward citation chains. Retrieve the full text when available and link each
addition to the gap it addresses. A sparse search result is not proof that a
scientific question is unstudied; report search coverage and unresolved access.
Reference counts must follow the review's scope and journal requirements rather
than a fixed quota.

## Tailor selection to the audience

Prioritize evidence that changes the audience's understanding or decision. Keep
quantitative findings from unfamiliar but relevant subfields. Remove off-topic
methods or applications, repeated background, and low-information duplication.
Retain foundational and competing evidence even if the audience already knows
it when the argument depends on that evidence. Do not discard a source because
of its language, country, or institutional affiliation. Provide an accessible
summary when its findings matter.

## Design the argument

Use one explanatory chain, for example environment chemistry -> structure
formation -> failure mechanisms -> engineering control. Avoid a catalogue that
merely lists material A, B, then C. Allocate the largest share of space to the
review's analytical core. A possible seven-section structure is introduction,
chemical environment, formation/structure/kinetics, failure mechanisms,
controlling factors, methods, and engineering implications with open questions.
Adjust proportions and citation density to the actual evidence and audience.

## Plan figures and tables

Separate original synthesis diagrams from reproduced or adapted source figures.
Original diagrams can show structures, causal chains, competing mechanisms,
conceptual stability regions, and methodological comparisons; they still need
source support for factual content. Published micrographs and quantitative curves
require source attribution and any applicable reuse permission. Use "adapted from"
only when adaptation accurately describes the reuse; do not invent underlying data.
Prioritize representative primary studies, reliable reviews, and recent evidence
that bears directly on the question.

## Export references

Write the requested bibliography in the chosen output directory. Include verified
title, author list, venue, volume, pages/article number, year, and DOI when present.
Short annotations can be recorded separately or in supported fields. Group BibTeX
entries with comments if useful, preserve citation keys, and validate import before
claiming the reference library has been updated. Tagging or library writes are
separate user-requested actions.
